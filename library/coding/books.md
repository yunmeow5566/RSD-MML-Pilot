# Reading is Cool!
In addition to writing a lot of code, it’s a good idea to read some high‑quality books on software development. You don’t need to read the whole book at once; just treat it as a relaxing bedtime hobby. 

Here are some books I’ve read and highly recommend:
- [Clean Code: A Handbook of Agile Software Craftsmanship](https://kcls.bibliocommons.com/v2/record/S82C2626919)
- [C++ Primer](https://kcls.bibliocommons.com/v2/record/S82C1269701)

I am borrowing more books from our library to see if I like them.
