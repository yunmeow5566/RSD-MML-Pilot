# Coding Conventions
When collaborating with other developers, following coding conventions is a baseline requirement. Different codebases may have their own styles or rules, and the key is consistency across the entire codebase, or at least within a single file.

Across all OOP languages, class names should be nouns, and function names should start with verbs.
Please review the coding conventions for the languages below:
- [C#](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions)
- [Java](https://google.github.io/styleguide/javaguide.html)
- [Python](https://peps.python.org/pep-0008/)
