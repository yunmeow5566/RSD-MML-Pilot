# Course Unit: Language with Neural Networks

## Goals
- Students can understand how natural language content is tranformed into high-dimensional vectors to feed into networks.
- Students can compare various tokenization methods.
- Students can understand why format matters for using LLM: token count consideration
- Students can understand few languange processing and understanding problems and connect it to machine learning models.
- Students can link NLP problems to real world tasks.
- Students can understand challenges of various language related problems.
- Students can apply embedding vectors to perform NLP tasks (assignment?)
- Students get exposed to transformer architecture and see how it can be used for multiple NLP tasks.
- Students can reason why we cannot blindly apply everything generated by LLM.

## Language related problems
- Sequence Labeling: Part‑of‑speech tagging, Named entity recognition (NER)
- Text Classification: topic, spam, sentiment analysis
- Language Modeling: next word prediction, auto-completion
- Machine translation: sequence to sequence
- Text Generation
- Question answering
- Summarization
- Information extraction
- Text Similarity / Retrieval
