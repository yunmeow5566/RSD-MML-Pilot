# Course Unit: Cloud APIs and Productization

# Goals
1. Students understand roles and responsibilities of services and client applications.
2. Students understand how client applications communicate with cloud services through REST APIs.
3. Students can define a basic server and a simple client application in Python.
4. Students can define initial scopes of final projects.
5. Students can identify integration points, potential challenges of scaling up a services and trade-offs in modern software products.
