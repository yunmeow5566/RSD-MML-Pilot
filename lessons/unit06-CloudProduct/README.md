# Course Unit: Cloud APIs and Productization

## Teaching Notes
- Might combine with unit09 and introduce both units right after unit01.

## Goals
1. Students understand roles and responsibilities of services and client applications.
2. Students understand how client applications communicate with cloud services through REST APIs.
3. Students can define a basic server and a simple client application in Python.
4. Students can define initial scopes of final projects.
5. Students can identify integration points, potential challenges of scaling up a services and trade-offs in modern software products.
6. Students can create and manipulate JSON content: students can understand list and dict concepts in JSON.

## Materials
- JSON format with Python: [link](https://docs.python.org/3/library/json.html)
- We can use this [repo](https://github.com/Azure/azure-sdk-for-python/blob/main/sdk/contentunderstanding/azure-ai-contentunderstanding/README.md) to review concepts about cloud APIs.
- REST API Client: [link](https://insomnia.rest/) we can use programs like this to interact with services directly.
