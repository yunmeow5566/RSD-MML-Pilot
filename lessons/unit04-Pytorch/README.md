# Course unit: Pytorch and neural networks

## Learning goals:
- Students can use Pytorch to implement a basic neural network structure. 
- Students can connect math concepts including loss function, gradient, linear and non linear functions to corresponding implementation in Pytorch. 
- Students can use multi dimension data to feed into Pytorch.
- Students can reason and implement a basic forward, backward propagation from loss.
- Students can train, validate and test neural network models with Pytorch. 
- Students can read open source code and have basic understanding about input, output, loss, network structures. 
- Students can understand various termination condition for training loops.
- Students can understand defintions of epoch and iteration.
- Students can compare and analyze the tradeoff between frequency of backward propagation and model converge speed.
- Students can explore huggingface models.
## Assignments
1. Read the description of at least one type of layers provided by Pytorch and describe when it can be used.
2. Explore huggingface models and identify one you might want to perform finetuning (prepare for PA3 or PA4).
