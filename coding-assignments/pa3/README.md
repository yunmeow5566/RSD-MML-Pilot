# Programming Assignment 3: Play with pretrained DL models

## Goals
- Students can investigate on various pretrained model and use them.

## Requirements
- Students should verify the capabilities of their computers: how big the model they can run inference, and expected latency.
- Students should define a scenario they want to solve with this model.
- Student should be responsible for defining metrics for measuring the model performance
- Students should have at least 20 meaningful test cases with GT to run evaluation.
