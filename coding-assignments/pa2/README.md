# Goals: 
- Students can learn to implement their own network with pytorch and perform model training and testing.
- Students can learn the tradeoff between model size, step size and training time.

# Instructions:
1. Pull the latest version of this repository. Feel free to copy the dataset to your own homework repository.
2. Review sample.py to understand every line in this file. Try to run it.
3. Modify the model structure, training strategy to minimize the testing loss.

# Requirements:
- Students need to train at least one model to fit a provided dataset. 
- All models need to come with an implementation to train (so the instructor can load and test).
- Students need to analyze results and share what they have tried to fit the function (add layers? expand size for hidden layers?)
- In final submission, students should include
1. at least one python file modified from `coding-assignments\pa2\sample.py`, with a corresponding output model named as `model*.pt`
2. One document to describe the corresponding testing loss for provided model(s), what has been tried and what is working/not working.
